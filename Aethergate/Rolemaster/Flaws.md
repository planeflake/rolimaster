# Flaws

Flaws are negative talents that provide additional talent points when taken. Each flaw's Point Gain is added to the character's available talent point budget. The GM should approve flaws and ensure they are meaningfully roleplayed. Rules for flaw limits and racial availability use the same checklist system as talents.

Source: *Rolemaster Standard System — Talent Law*, Appendix: Flaws By Cost, p. 112.
